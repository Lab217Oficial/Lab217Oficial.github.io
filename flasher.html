ESP32 / ESP8266 — flasheo directo

[ CHIP: ESP32-S3 ]

WiFi Monitor

Firmware de monitoreo Wi-Fi para ESP32-S3 (proyecto AHAU CTF). Se flashea completo en el offset 0x0.

  1. Conecta el ESP32-S3 por USB.
  2. Pulsa Instalar y elige el puerto serie.
  3. Si no aparece, mantén BOOT y toca RESET para entrar en modo descarga.
Navegador no compatible — mira el método manual. Necesitas servir la página por HTTPS o localhost.
Descargar .bin  ·  SHA y notas de versión próximamente.

RP2040 / RP2350 (Pico) — modo BOOTSEL

[ MÉTODO ]

Arrastrar y soltar .uf2

Las placas RP2040 y RP2350 (Raspberry Pi Pico y Pico 2) no se flashean por Web Serial: se montan como una memoria USB. Es aún más simple.

  1. Desconecta la Pico.
  2. Mantén presionado el botón BOOTSEL.
  3. Conéctala por USB sin soltar el botón.
  4. Aparecerá una unidad RPI-RP2.
  5. Copia el archivo .uf2 del proyecto a esa unidad.
  6. La placa se reinicia sola con el nuevo firmware. Listo.
// CÓMO APARECE UN FIRMWARE AQUÍ

Cuando un proyecto publique su release oficial en GitHub con un archivo .uf2 adjunto, aparecerá aquí automáticamente como tarjeta de descarga.

Seguridad

!FLASHEA BAJO TU PROPIO RIESGO.

Nunca escribas firmware en el que no confíes. Flashear reemplaza el software de tu dispositivo y puede borrar datos. Todo nuestro firmware es open source y verificable antes de instalarlo. En Linux quizá necesites permisos sobre el puerto serie (grupo dialout / reglas udev).
